# Logo du restaurant

Déposez ici le fichier du logo sous **un** de ces noms :

    assets/logo.gif     ← recommandé (votre fichier actuel)
    assets/logo.png
    assets/logo.svg
    assets/logo.jpg
    assets/logo.webp

`nyabungo2.html` le charge automatiquement dans la colonne droite du hero (test des
extensions dans cet ordre, en s'arrêtant au premier fichier trouvé).

Si aucun fichier n'est présent, le menu affiche le monogramme SVG embarqué
(N orange, H sombre, R brun, verres rouges, ruban) : la page n'affiche **jamais**
d'image cassée, ce qui garantit la démo même sans ce dossier.
