Aperçu dans un cadre téléphone

Cet aperçu charge nyabungo2.html, servi avec assets/ : le cas réel de l'option B. La racine / du site pointe déjà sur cette page (vercel.json), donc le QR code peut envoyer vers l'URL sans nom de fichier.

Mise en ligne sur Vercel — option B retenue (dépôt entier)

  1. Option B (retenue) — le dépôt entier. vercel.com/new → importer vizane156/menu-digital → Framework Preset = Other, Build Command = vide, Output Directory = . Déploie tel quel : vercel.json sert déjà le menu sur / et met les images en cache 30 jours.
  2. Option A (repli, si besoin) — un seul fichier : python3 build-standalone.py puis glisser deploy/index.html. 16 photos + logo encodés en base64, zéro dépendance assets/.
  3. Le plus propre — le dépôt entier. Importe le repo GitHub dans Vercel, Framework Preset = Other, Output Directory = . Tu gardes les fichiers séparés (meilleur cache, page HTML plus légère : 163 Ko + images en lazy-load).
  4. Reconstruire le fichier autonome après avoir ajouté les 6 visuels manquants : python3 build-standalone.py.
Visuels : les 16 photos sont intégrées (logo réel inclus, agrandi à la taille de la carte signature). Le repli vectorielle reste en secours : si un fichier manque ou ne charge pas, l'illustration du plat reprend la place toute seule — aucune image cassée possible pendant la démo.

Script de démo (6 minutes)

  1. Accueil — laissez tourner le bandeau « Signature du chef » : 5 plats défilent seuls, puis montrez qu'on peut les faire glisser du doigt.
  2. Le logo — colonne droite du hero ; les puces indiquent la table et les horaires.
  3. Ajouter — un tap sur le « + » d'une carte : le panier se remplit, l'illustration vole dans la barre (à tester vite, c'est l'effet qui fait l'effet).
  4. Fiche plat — tap n'importe où sur la carte : taille de portion, accompagnement, niveau de piment, prix recalculé en direct.
  5. Note cuisine — « sans piment pour un enfant » : montre l'attention au détail.
  6. Envoyer — numéro de commande, puis suivi : anneau ETA, timeline reçue → préparation → prête → servie. Ça s'avance tout seul en ~40 s.
  7. Payer — Lumicash, EcoCash, carte ou espèces, avec reçu imprimable.
  8. Réseaux — pied de page : WhatsApp, Facebook, Instagram, TikTok, site officiel, itinéraire Google Maps.
Avant de brancher le vidéoprojecteur : ouvrez la page, passez en thème clair puis sombre (le bandeau du navigateur suit le thème), changez la langue FR/EN d'un tap, et faites défiler le menu d'un pouce. Le logo réel se place dans assets/logo.gif : dès que le fichier est là, il remplace le monogramme vectoriel sans toucher au code.
